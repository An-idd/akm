# Agent 产出物约定

> 把本节内容追加到项目的 CLAUDE.md / AGENTS.md 中即可生效，适用于 Claude Code、Codex、Cowork 等所有 Agent。

## 目录约定

- 所有**交付物**（报告、脚本、数据、文档）写入 `artifacts/`，按域分类：`artifacts/research/`、`artifacts/code/`、`artifacts/data/`、`artifacts/docs/`
- **中间产物**（草稿、调试脚本、临时数据）写入 `tmp/`，可随时清空，永不被引用
- 拿不准算哪类时，问用户，不要猜

## 命名约定

- 格式：`YYYY-MM-DD-主题-类型.ext`，例如 `2026-07-15-competitor-scan-report.md`
- 迭代时**原地更新同一文件**，禁止产生 `_v2`、`_final` 后缀
- 旧版本确需保留时，移入 `artifacts/archive/` 并在 INDEX.md 标记"已取代"

## 登记约定（核心）

每次在 `artifacts/` 下新建或更新文件后，**必须**同步更新 `artifacts/INDEX.md` 中对应行：

```
| 日期 | 文件 | 摘要 | 状态 | 来源 |
|------|------|------|------|------|
| 2026-07-15 | research/2026-07-15-competitor-scan-report.md | A/B/C 三家定价均上调，B 家新增企业版 | 交付 | 月度竞品扫描；输入：官网+新闻检索 |
```

- **摘要**：写结论，不写"这是一份关于……的文件"
- **状态**：`草稿` / `交付` / `已取代 → 指向新文件`；拿不准就标草稿
- **来源**：一句话任务描述 + 主要输入（数据源、上游文件）
- INDEX.md 只增改行、不重排，保持 git diff 干净

## 读取约定

- 会话涉及历史产出物时，**先读 `artifacts/INDEX.md`**，按需再读具体文件
- 忽略状态为"已取代"的文件；文件内容与 INDEX 冲突时以 INDEX 为准并向用户确认
- 复用已有脚本/结论优先于重新生成；发现可复用项时先告知用户

## 纪律

- 取代关系拿不准就留空并问用户——错误的溯源比没有溯源更害人
- 不确定某文件是否权威版本时，问用户，不要基于猜测继续工作
