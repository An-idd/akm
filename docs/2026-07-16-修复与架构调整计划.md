日期：2026-07-16
依据：独立评审报告（子 agent，2026-07-16）+ 定位讨论（结果为主体、规则/偏好升一等）
**Goal:** 修掉评审确认的全部真 bug，把三个失实卖点变成真实现，完成坐标化目录调整——让"卖可信溯源的产品自己经得起溯源"。

**Architecture:** 四个批次顺序执行：T0 正确性（溯源可信）→ T1 稳定性与成本（防卸载）→ T2 兑现叙事（verified / preference / 拉模型水合）→ T3 架构（坐标目录、隐私披露）。每批次结束跑全量回归并重装真机二进制。

**Tech Stack:** bun + TypeScript，现有 monorepo，无新依赖。

## Global Constraints

- 三承诺不可破：数据永远可 grep 的普通文件；hook 静默失败不阻塞宿主；拿不准留空
- manifests.jsonl 保持 append-only、last-write-wins by id；文件一旦落盘永不改名搬家（T3 新目录只影响新写入 + 一次性迁移）
- 每批次验收：`bun test` 全绿 + `bash scripts/e2e.sh` 全绿 + 重编译安装 `~/.akm/bin/akm`
- hook 关键路径预算不变：capture/hydrate/distill --detach 均 <100ms

- [ ] 实现：unsure 优先，其后全词匹配：
```ts
export function parseVerdict(raw: string): JudgeVerdict {
  const text = raw.toLowerCase();
  if (/\bunsure\b/.test(text)) return "unsure";
  if (/\bnot\s+supersedes?\b/.test(text)) return "unsure";
  if (/\bsupersedes\b/.test(text)) return "supersedes";
  if (/\bunrelated\b/.test(text)) return "unrelated";
  return "unsure";
}
```

- [ ] 抽出打分纯函数并写测试：一年前 verified 条目 vs 昨天未验证条目，verified 不被衰减清零；preference 类型完全豁免衰减与 stale
- [ ] 实现：
```ts
// preference 是规则不是时效资产：豁免衰减与 stale
const decay = row.type === "preference" ? 1 : Math.exp(-ageDays / 60);
const floor = row.verified > 0 ? 0.3 : 0; // verified 资产衰减有下限
const freshness = Math.max(decay, floor) * (stale && row.type !== "preference" ? 0.3 : 1);
```

## 执行与验收

顺序：T0 → T1 → T2 → T3，每批次末尾：`bun test` + `bash scripts/e2e.sh` + 重编译双二进制 + `akm init --yes` 重装。全部完成后：真实会话冒烟（新会话首条消息触发相关性注入 + 回合结束防抖生效 + `akm verify` 走一遍）+ 更新记忆文件。

**明确不做**：技能自动学习、向量检索、compact 自动触发、`.akmpack`、entryId 掺 body。
**明确缓做**（等团队/共享期信号）：MCP `akm_register` 的 namespace 信任分区（当前硬编码 self，单用户期风险面可接受；P2 共享上线前必须做）；水合注入内容的消毒（记忆投毒防御，单用户自产自销期威胁模型不成立，导入外部包前必须做）。
